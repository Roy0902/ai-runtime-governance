## 2. Scope

**In scope:**

- Public email/password registration, normalization, duplicate safety and
  one-time email verification.
- Password rules, Argon2id verifiers, rehash and bounded hash admission.
- Mandatory TOTP enrollment, replacement, replay prevention and pending expiry.
- Recovery codes, recovery login and acknowledged standalone regeneration.
- Persistent human sessions, idle/absolute expiry, recent authentication and
  revocation.
- Private scope creation, ownership enforcement and host-only disable/re-enable.
- Host-operator recovery, gateway entitlement and host audit.
- Verified-email password reset.
- Bounded abuse/source admission, progressive cooldown and mail delivery retries.
- The private account UI needed to exercise these journeys.

**Out of scope (explicit):**

- Timeline reads, prompt guard, gateway forwarding, provider credentials, event
  ingestion, workspaces, BYOK, archives, attachments, output scanning, per-tool
  action governance, deletion/erasure and verified-email recycling.
- Public admin UI or any HTTP host-operator surface.
- Real outbound email; acceptance uses a local capture sink.
